# Expectation–Maximization for RSS noise calibration

Reproducible algorithm study by Camilo Vásquez, Yachay Tech University. The assigned EM implementation uses **C++17** and the standard library. Python supports synthetic data generation, the RTI/KNN experiment, analysis and figures.

## Repository contents

- `em.cpp`: EM for two univariate Gaussian components with fixed zero means, including a numerical demonstration.
- `compilar_cpp.py`, `em_cpp.py`: compilation helper and interface used by the experiment.
- `simulacion_rti_em_knn.py`, `analizar_resultados.py`: synthetic experiment and paired analysis.
- `results/python_preliminary/`: configuration, per-case predictions, calibration diagnostics and aggregate results. The folder name is retained; `parametros.json` records the executed C++ backend and source hash.
- `figures/`: analysis figures and their data are generated by the analysis script.
- `tests/`, `validation/`: regression and C++/Python parity checks. The Python implementation is a validation reference.
- `report/`: IEEE Conference manuscript, PDF and complete Overleaf source bundle.
- `slides/Presentacion_RTI_EM.pdf`: presentation PDF.

## Build and demonstrate C++

Requires a C++17 compiler such as g++. From the repository root in PowerShell:

```powershell
New-Item -ItemType Directory -Force build | Out-Null
g++ -std=c++17 -O2 -Wall -Wextra -pedantic -static em.cpp -o build/em.exe
.\build\em.exe --demo
```

Alternatively, `python compilar_cpp.py` invokes g++ and records the compiler version, flags and source hash. The executable supports `--demo` and `--fit`. The latter reads `N maxiter tolerance p0 sigma1_0 sigma2_0 sigma_floor`, followed by N residuals from standard input, and prints the estimated parameters, iteration count and convergence flag. `nan` requests the automatic initial standard deviation.

## Reproduce the experiment

Requires Python 3.10 or later, NumPy, Matplotlib and the C++ compiler:

```powershell
python -m pip install -r requirements.txt
python .\simulacion_rti_em_knn.py --output-dir .\results\python_preliminary
python .\analizar_resultados.py
python -B -m unittest discover -s tests -v
```

All calibration and initialization fits call the compiled C++ executable. The principal configuration uses seed 7, 12 nodes, 66 links, 100 pixels, 500 paired queries and 5,000 calibration residuals. Recovery diagnostics use five sample sizes with 20 repetitions each; initialization diagnostics use 20 starts on one fixed sample. Full settings and implementation provenance appear in `parametros.json`.

## Results and scope

| Estimator | Mean localization error (m) |
|---|---:|
| Constant room center | 2.407 |
| KNN fingerprints | 2.618 |
| RTI with Fisher scaling | 3.062 |
| Tikhonov RTI | 3.244 |

The signal-based methods do not beat the constant-center control in mean error on the recorded queries. Fisher scaling is algebraically equivalent to changing the effective regularization to alpha/gamma, with corresponding scaling of the diagonal stabilizer. The comparison does not isolate a specific EM benefit over independently tuned RTI.

The EM study evaluates recovery under the same distribution family used to generate residuals. Its time complexity is Theta(I N) for I executed iterations and two fixed components; the stored responsibility vector uses Theta(N) auxiliary memory. Convergence of the stopping criterion does not guarantee a global maximum.

All observations are synthetic. The experiment does not model electromagnetic propagation, CSI, materials or rubble, and does not validate a physical person-localization system. The source radio experiment used IEEE 802.15.4 nodes. The implementation estimates global noise parameters and does not impute missing RSS measurements.

## Manuscript and sources

`report/main.tex` uses the official IEEEtran conference class. `report/Overleaf_RTI_EM.zip` contains a standalone manuscript project with figures, bibliography and the C++ source. The report identifies the data files supporting its claims and the remaining validation limits.

Foundational references include Dempster, Laird and Rubin (1977), Wu (1983), Wilson and Patwari (2010), and Bahl and Padmanabhan (2000). Complete references and DOIs appear in the manuscript bibliography.
